# Architecture Decision Records

Architecture Decision Records (ADRs) capture significant, durable project
decisions and their consequences. Safety-critical decisions must be recorded
here before or together with implementation.

Each ADR uses the following sections:

1. Title
2. Status
3. Context
4. Decision
5. Consequences

Accepted records are immutable descriptions of their decision. A later change
should add a new ADR that supersedes the earlier record rather than silently
rewriting history.
