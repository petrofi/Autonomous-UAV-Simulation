# Security Policy

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities, real credentials, private keys,
certificates, tokens, personal configuration, sensitive flight data, or precise
operational details in a public issue.

Use GitHub's private vulnerability reporting feature if it is enabled for this
repository. If it is unavailable, contact the repository owner privately through
an agreed channel before sharing sensitive details. Include a concise impact
summary, affected documentation or component, safe reproduction conditions, and
suggested mitigations. Keep any reproduction limited to authorized simulation
environments.

## Project Maturity

The project is currently architecture and repository scaffolding only. It does
not provide production, real-flight, or complete security guarantees. Security
work is planned as defensive, security-oriented engineering using
defence-in-depth, resilient communication, explicit trust boundaries, and safe
failure behavior.

Security reports involving weaponization, unauthorized access, or unsafe
real-world flight operations are outside the intended scope of this civil
simulation research project.
